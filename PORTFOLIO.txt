================================================================================
  PROJECT OVERVIEW
================================================================================

  Name      : LyreAura
  Type      : Desktop Application (Windows)
  Language  : Python 3.10+
  UI        : Tkinter (native GUI — no Electron, no browser, minimal RAM usage)
  Source    : Single-file architecture (main.py)

  LyreAura is a Pomodoro productivity timer combined with a full-featured
  YouTube Music player. It was born from a real personal problem: spending
  hours programming without moving, which causes back pain, eye strain, and
  burnout. Rather than using an existing app, I built one tailored to exactly
  what I needed — and added YouTube music integration because I genuinely
  can't focus without music.

================================================================================
  THE PROBLEM I SOLVED
================================================================================

  Problem  : Long programming sessions with no movement reminders + no native
             music player that integrates with my workflow.

  Solution : A lightweight desktop app that:
             1. Tracks time using the Pomodoro Technique (25-min work blocks)
             2. Forces a stand-up prompt on every break (can't be dismissed
                without acknowledging it)
             3. Plays YouTube audio in the background using the official
                YouTube Data API v3 — no piracy, no grey areas
             4. Saves your queue and playlists between sessions so you never
                lose your setup

================================================================================
  FEATURES BUILT
================================================================================

  POMODORO TIMER
  ─────────────
  • Circular countdown ring drawn with Tkinter Canvas arcs (custom rendering)
  • Configurable Work / Short Break / Long Break durations
  • Auto-transitions between work and break phases
  • Stand-up reminder popup with rotating healthy stretch tips
  • Session counter (e.g., "Session 2 of 4")
  • System tray icon with live countdown tooltip (minimize-to-tray)

  YOUTUBE MUSIC PLAYER
  ────────────────────
  • YouTube Data API v3 integration — search filtered to Music category
  • Audio extraction via yt-dlp + FFmpeg (MP3 conversion for reliable playback)
  • pygame mixer for low-latency audio playback
  • Scrolling "Now Playing" marquee label
  • Volume slider with mute button (remembers pre-mute level)
  • Previous / Play-Pause / Next / Shuffle controls

  QUEUE SYSTEM
  ────────────
  • Add any search result to a playback queue
  • Reorder queue items (Move Up / Move Down)
  • Auto-advance: next queued track plays automatically when current ends
  • Double-click any queue item to play immediately

  PLAYLIST MANAGER
  ────────────────
  • Create named playlists with a custom modal dialog
  • Add tracks from search results to any playlist
  • Load playlist into the player (populates search list without auto-playing)
  • Queue an entire playlist with one click ("Play All")
  • Remove individual tracks, save, or delete playlists
  • All playlists saved to playlists.json — persist between app restarts

  SESSION PERSISTENCE
  ───────────────────
  • Last search results and queue saved to session.json on every change
  • On launch, the previous session is fully restored — songs, queue, position
  • API key stored in .env and loaded via python-dotenv

  RESIZABLE / SCROLLABLE UI
  ─────────────────────────
  • Window is freely resizable and movable
  • All content wrapped in a scrollable Canvas frame
  • Mouse-wheel scroll supported
  • Minimum window size enforced (380×500) to prevent broken layouts
  • Content stretches horizontally as window widens

  DEPLOYMENT & POST-BUILD
  ────────────────────────
  • Standalone .exe created via PyInstaller (55MB, bundled dependencies)
  • Freeze-safe path handling for .env and JSON persistence
  • Windows Startup integration (auto-starts app on login)
  • GitHub CI-ready structure with .gitignore and .env.example templates
  • Final release published to GitHub with binaries attached

================================================================================
  WHAT I LEARNED BUILDING THIS
================================================================================

  1. Threading discipline — pygame and Tkinter both have their own event loops.
     Learning to safely pass data between threads (using root.after() to
     schedule UI updates from worker threads) was the biggest challenge.

  2. API design reality — YouTube's audio URLs expire and can't be streamed
     directly by pygame. I had to design a download-then-play flow using
     temp files, which taught me about real-world API limitations.

  3. Tkinter's scrollable layout — Tkinter doesn't have a built-in scrollable
     frame. Building one with Canvas + create_window() and binding Configure
     events to update scroll regions was a great deep-dive into how Tkinter's
     geometry system actually works.

  4. UX > features — The first version auto-played on click. Users hated it.
     Separating selection from playback (adding an explicit Play button) was
     a small change that made the app feel much more intentional.
